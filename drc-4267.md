[DRC-4267](https://linear.app/recce/issue/DRC-4267) — The dashboard renders raw prompt text, so a credential pasted into a prompt is displayed on the session card

## User value

A person who ever pasted a credential into a prompt notices this once the session card's instruction line stops echoing it back onto their screen. P2, keep: without a redaction filter the mid-flight promise's activity line keeps showing raw operator text, credentials included, instead of a safe description of the work.

## Problem

Cargento renders harness transcript prompt text on the dashboard: the `instruction` line, `last_prompt`, the `ai-title` fallback in `prompt_title`, the observer goal, and Codex titles. A sweep of the local Claude store found live Anthropic credentials (`sk-ant-api03-…`, `sk-ant-oat01-…`, `sk-ant-ort01-…`) sitting in ordinary prompt history and rendered onto session cards.

## Outcome

Resolved and verified as delivered in PR #225 (commit `9ffc90a3`) and PR #230 (commit `a744f8ce`). Implemented `records.redact_secrets` and `records.redact_clip` with measured shape patterns covering 14 credential shapes, replacing secrets with visible markers (`…REDACTED`) in `records.safe_text` and `aggregate._redact_published_text`. Documented in `docs/design-credential-redaction.md` and `SECURITY.md`. All synthetic test fixtures verified in `RedactSecretsTest` in `tests/test_records.py`. Post-merge reconcile receipt posted to Linear and issue marked Done.
