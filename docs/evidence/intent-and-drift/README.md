# Intent and drift teammate evidence

[Share the sidecar prompt](PROMPT.md) now with a developer who uses Claude Code for real work. Their agent can run current `main` against a recent session and record what the drift panel says. This is exploratory, agent-operated evidence. Anyone who reads that prompt or watches the sidecar pass has seen the panel's controls and cannot then count as a cold participant.

Reserve two other developers for uncoached walks. Run those only after the prerequisite checks in the [cold-study protocol](COLD_STUDY_PROTOCOL.md) are complete and any fixes are on `main`. Give each participant only the [kickoff and consent note](PARTICIPANT_KICKOFF.md). A facilitator gives the protocol to their observer agent without showing it to the participant. If the participant reads the protocol or receives control hints before the walk, label the run exploratory. [The run template](RUN_TEMPLATE.md) records either kind of evidence.

Starting Cargento scans available local session stores across its supported harnesses, not just the three Claude Code sessions an agent shortlists. Its loopback board can display session titles and prompts. Each participant must know that before the sidecar starts. The agent should inspect and report only the selected sessions, and the participant decides separately whether to allow a model reading in the browser.

This repository is public. Commit only a participant-approved, redacted copy of the run template under this directory. Keep raw transcripts, saved goals, checklist text, clipboard contents, local paths, session IDs, and unredacted screenshots out of Git. Save original captures under the gitignored `docs/screenshots/` tree, in the cold-study folder the facilitator protocol specifies or `intent-and-drift-sidecar/` for exploratory runs. Keep that checkout available until a person reviews the captures and any approved evidence reaches the development record. A public report can link to a public verdict without repeating private material. Use a branch and a PR into `main` for the public report; the [PR workflow](../../../AGENTS.md#pr-workflow) applies.
