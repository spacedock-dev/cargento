[DRC-4180](https://linear.app/recce/issue/DRC-4180) - --diagnose reports "overrides none" while CARGENTO_HOME is relocating everything Cargento writes

## User value

A person inspecting or pasting a --diagnose report sees the effective Cargento home directory and any active overrides, including CARGENTO_HOME, rather than being told overrides none while a directory move is in effect. P1, keep.

## Problem

server.py --diagnose builds its overrides field from STORE_ENV_VARS, which holds the six per-harness store variables. CARGENTO_HOME is defined separately in CARGENTO_HOME_ENV and is omitted from that collection, so setting CARGENTO_HOME still prints overrides none. In addition, the text report only displays home (the user's OS home) without stating the effective Cargento home directory, and --diagnose --json omits cargento_home and excludes CARGENTO_HOME from its env object.

## Proposed approach

1. In cargento_runtime/diagnostics.py:
   - In diagnose(application):
     - Include CARGENTO_HOME in the env mapping when present in os.environ.
     - Add cargento_home: config.state_home to the returned dictionary.
     - Also check XDG_DATA_HOME if set in os.environ and include in env.
   - In render_diagnosis(report):
     - Add cargento home <path> beneath home <path>.
     - The overrides line automatically renders CARGENTO_HOME when present in env.
2. Update tests in test_config_diagnostics.py and test_diagnostics.py to assert both text and JSON outputs.

## Acceptance criteria

- AC1 (offline): server.py --diagnose prints cargento home <path> matching the effective state_home. Verified by: test_diagnostics.py assertion.
- AC2 (offline): When CARGENTO_HOME is set in the environment, server.py --diagnose includes CARGENTO_HOME=<value> in the overrides line. Verified by: test_diagnostics.py.
- AC3 (offline): server.py --diagnose --json contains cargento_home and includes CARGENTO_HOME in env when set. Verified by: test_config_diagnostics.py.

## Test plan

- Unit test in tests/test_config_diagnostics.py asserting report dictionary keys and env contents.
- Formatting test in tests/test_diagnostics.py asserting rendered lines.
- Run full test suite under coverage.
