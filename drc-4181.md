[DRC-4181](https://linear.app/recce/issue/DRC-4181) — State files from runs that never exited cleanly accumulate in ~/.cargento, each holding a dead run's capability tokens

## User value

State files from runs that never exited cleanly (e.g. SIGKILL, abnormal termination, crash) are swept on dashboard startup rather than accumulating indefinitely in `~/.cargento`, expiring dead capability tokens and preventing disk clutter. P1, keep.

## Problem

When a dashboard run does not exit cleanly (e.g. killed with SIGKILL, crash, abandoned test harness), its `cargento-<port>.json` state file is left behind. Each file carries the run's capability tokens and port metadata. Over time, multiple stale files accumulate in `~/.cargento`.

## Proposed approach

1. In `cargento_runtime/lifecycle.py`:
   - Implement `pid_exists(pid: int) -> bool`:
     Checks whether a process with `pid` is currently running (using `os.kill(pid, 0)` on POSIX and handling errno/winerror).
   - Implement `sweep_stale_states(config: RuntimeConfig) -> list[int]`:
     Discovers `cargento-<port>.json` in `cargento_home(config)`. For each integer port:
     If `probe_port(port, timeout=0.1)[0] == "closed"` AND `port_released(config, port)` is True:
     Inspect recorded `pid`: if no pid or `not pid_exists(pid)`:
     Call `remove_state(config, port)`.
     This ensures safety against a concurrent dashboard mid-start on the same port (since a starting dashboard holding the port or with an active PID is never swept).
2. In `cargento_runtime/cli.py`:
   - Call `lifecycle.sweep_stale_states(config)` during dashboard startup prior to binding.
3. In `tests/test_lifecycle.py`:
   - Add unit tests for `pid_exists`, `sweep_stale_states`, asserting that dead state files are swept while active or mid-start instances are preserved.

## Acceptance criteria

- AC1 (offline): A starting dashboard removes state files for ports that probe dead with dead recorded PIDs. Verified by: unit and subprocess tests in `tests/test_lifecycle.py`.
- AC2 (offline): A state file for an active PID or an in-use port is not swept. Verified by: `test_lifecycle.py`.

## Test plan

- Test `sweep_stale_states` with dead PID state files, live PID state files, and busy ports.
- Verify full test suite passes with coverage.
