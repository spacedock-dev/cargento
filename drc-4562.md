[DRC-4562](https://linear.app/recce/issue/DRC-4562/every-departure-row-publishes-the-producers-own-account-of-what-it) — Every departure row publishes the producer's own account of what it read, and no surface renders it

## User value

The one sentence saying how much evidence a departure actually rested on is published on every row and shown on none. P2, sharpen: **the reader can see how far the evidence went, not only what it concluded.**

## Problem

`departures.published` passes the whole stored record through except the withdrawal mark, so every row carries `cutoff_text`, the producer's own account of what it read (e.g. "Read 14 entries, 9 of them the session's own account"). In `next-session.js:nextSessionDepartureRow`, the baseline and evidence citations are rendered, but `cutoff_text` is omitted from the DOM.

## Proposed approach

1. In `cargento/skills/cargento/cargento_runtime/web/next-session.js`:
   - In `nextSessionDepartureRow(row, current)`, render `cutoff_text` beside the evidence line in `<p class="next-session-departure-base">`:
     `(text("cutoff_text") ? ' · ' + esc(text("cutoff_text")) : "")`
2. Update frontend asset byte and digest pins across test files (`test_next_page.py`, `test_next_flag.py`, `test_focus.py`).
3. Add unit test asserting `cutoff_text` renders in departure rows.
4. Run full pre-PR test suite.
