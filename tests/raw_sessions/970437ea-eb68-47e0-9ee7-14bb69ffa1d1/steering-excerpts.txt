## The constraints actually holding it down

1. **Install friction is the binding one.** ccusage is `npx`. Cargento is a plugin install plus manual per-harness hook and MCP registration. The report has to run as one command against transcripts, with the dashboard as the upsell, or the loop never starts.
2. **The metric punishes good practice.** Run six agents deliberately and your idle time balloons. Needs normalizing per session, or your best users score worst.
3. **Framing decides everything.** Indict the paradigm, not the reader. A number that shames you doesn't get posted; one that signals how heavily you use agents does.
4. **Idle isn't all waste.** Some of that 184 hours was me reading output. The honest claim is agent idle, not human idleness, and the gate-blocked slice is the pure-waste subset.
5. **Codex's gate data needs approvals enabled**, and its gate events drop the tool name at the hook. Claude has four detection sources; Codex has one.
6. **Per-session tokens are Claude-only** (`records.py:640` gates `usage_signal` on the harness), so don't promise cost per side.
7. **Novelty is the weakest link in this answer.** One lens searched and found nothing measuring agent wait time; that's one query, not a survey. DORA review latency and Copilot acceptance rate are the adjacent prior art. Verify before building.

## Four findings that narrow the feature

- **There is no gate-answered timestamp.** `events.py:653`: Claude has no hook for a permission being *granted*; `Stop` and `UserPromptSubmit` are the only overlays that end a wait and neither fires mid-turn. A test pins that absence deliberately. So gate latency is an upper bound quantised to the reconcile interval, never a measurement.
- **Survivorship bias aimed at the headline.** `collectors/claude.py:833` nulls `blocked_since` when a session exits while blocked — "moot, not blocking". The worst waits, where nobody came back, are the ones erased.
- **Codex contributes almost nothing.** Its `needs_input` is entirely event-overlay and needs approvals enabled; under `codex exec` no prompt opens and no hook fires. A two-harness chart would report "Codex interrupts you less" as an instrumentation artifact.
- **WakaTime is the precedent, and it's a warning.** ~500k developers, badges, leaderboards, profile embeds, and a headline stat of 51 minutes of programming per day. Never went viral. A time-accounting number about your own shortfall gets fixed quietly, not posted.
