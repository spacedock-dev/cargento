3. 橋要做到「不用重寫」：skill 原封不動，spacedock 只是把它包起來。

## 三個讓人願意試的做法

**1. behavior diff 順便把 skill 的結構畫出來。**
behavior diff 跑完，除了 before/after，多一小段：

```
這個 skill 實際上有 4 個步驟、2 個你會停下來決定的地方。
before: 步驟 2 被跳過 1 次 / 3 次
after:  步驟 2 被跳過 0 次 / 3 次
```

使用者第一次「看到」自己的 skill 是一個 workflow。這不是推銷，是事實。survey skill 現在已經在做類似的事（讀 session history、報 implicit workflow、問要不要 commission）。behavior diff 可以接同一條路。

**2. 在痛的當下出現，不是在 landing page。**
- skill 第 3 步失敗、使用者重跑 → 「spacedock 可以從第 3 步接著跑」

**3. 轉換要免費。**
`spacedock commission --from-skill foo.md`：skill 檔不改，產生一個 workflow 把它的步驟切成 stage。使用者發現不好用就刪掉 workflow，skill 還在。試的成本接近零。
